# Приём заявок в Google Таблицу (бесплатно, 10 минут)

Заявки с формы падают строкой в Google Таблицу, а вам в Telegram приходит уведомление.
Сервер не нужен — скрипт живёт внутри таблицы.

## 1. Таблица и скрипт

1. Создайте таблицу на [sheets.new](https://sheets.new), назовите «Ася — предзаказы».
2. **Расширения → Apps Script**. Удалите то, что там есть, и вставьте содержимое [Code.gs](Code.gs). Сохраните (Ctrl+S).
3. **Развернуть → Новое развёртывание** → шестерёнка → **Веб-приложение**:
   - Выполнять от имени: **Я**
   - Кому доступно: **Все**
4. **Развернуть** → разрешите доступ к своему аккаунту (Google предупредит, что приложение не проверено: «Дополнительно → Перейти»).
5. Скопируйте **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).
6. Вставьте его в [`landing/config.js`](../config.js) → `formEndpoint`.

Проверка: откройте URL в браузере — должно показать `{"ok":true,"service":"asya-preorders"}`.

> Поменяли `Code.gs` — нужно **Развернуть → Управление развёртываниями → карандаш → Версия: новая**.
> Иначе по старому адресу будет работать старый код.

## 2. Уведомления в Telegram (по желанию)

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой chat id у [@userinfobot](https://t.me/userinfobot).
4. В Apps Script: **Настройки проекта (шестерёнка) → Свойства скрипта**:
   - `TG_TOKEN` = токен бота
   - `TG_CHAT_ID` = ваш chat id

Токен хранится в свойствах скрипта, а не на сайте, поэтому посетители его не увидят.

## Что лежит в таблице

Имя, контакт, кто это (для себя / ИП / компания), сфера, размер, задачи, каналы связи с клиентами, чем пользуется сейчас, тариф, когда хотят начать, комментарий,
а ещё **utm-метки**: по ним видно, какое объявление привело человека.
